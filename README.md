# SQA DANA - UTS CSI704

Repositori ini berisi dokumentasi dan simulasi penerapan Software Quality Assurance (SQA) pada aplikasi dompet digital DANA.

Disusun untuk memenuhi tugas Ujian Tengah Semester mata kuliah CSI704 - Software Quality Assurance, Program Studi Teknik Informatika, Universitas Esa Unggul.

**Penyusun:** M Hafidz Al Zafaran (NIM 20240801110)



## Ruang Lingkup Fitur

1. Registrasi dan login (PIN, OTP, biometrik)
2. Top-up saldo
3. Transfer ke sesama DANA atau bank
4. Pembayaran QR
5. Riwayat transaksi
