# Requirement Fitur Top-Up Saldo

| ID | Requirement | Jenis |
|----|-------------|-------|
| FR-03 | Pengguna dapat menambah saldo melalui transfer bank, minimarket, atau kartu debit | Fungsional |
| FR-04 | Saldo bertambah otomatis setelah pembayaran terkonfirmasi | Fungsional |
| NFR-02 | Proses top-up selesai maksimal 5 detik setelah konfirmasi pembayaran | Non-fungsional |
| NFR-03 | Data pembayaran dienkripsi saat dikirim | Non-fungsional |
